📥 Importar de planilha

1️⃣ Baixar o modelo

Baixe a planilha modelo, preencha com blocos, ações e responsáveis, e depois faça upload aqui.

📖 Formato da planilha
A planilha tem 2 colunas:
  • AÇÃO — nome da atividade OU título do bloco no formato 1. NOME DO BLOCO
  • RESPONSAVEL — área responsável (deixe vazio para linhas de bloco)
Colunas opcionais que também são reconhecidas:
  • INICIO — data planejada (formato DD/MM/AAAA ou AAAA-MM-DD)
  • TERMINO — data planejada de término
  • STATUS — NÃO INICIADO / EM ANDAMENTO / CONCLUÍDO / NÃO SE APLICA
  • MARCO — S / SIM / TRUE para marcar ⭐
  • OBS — observação/comentário
Áreas separadas por + ou , viram múltiplos responsáveis. Barras / ficam juntas (ex: OBRA/JURIDICO).
2️⃣ Enviar planilha preenchida

⬆️ Importar backup

  • Projetos com o mesmo id de um projeto já existente são substituídos pela versão do arquivo.
  • Os demais projetos do sistema não são alterados.
  • Modelos e áreas do arquivo são somados aos existentes; anexos vão para o armazenamento do sistema.
  • Depois de importar, a empresa de cada projeto pode ser trocada em Projeto › Detalhes.
